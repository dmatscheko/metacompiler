# WHY A MEDIAN OVER DRAWS AND NOT A NUMBER. A binary's instruction count depends on
# its CODE LAYOUT, and layout is perturbed by things that change no semantics. One

#   17.353 17.494 17.620 17.911 17.915 17.916 17.916 18.018 18.023 18.182 G

# 4.8%, bimodal, from a file NAME. A module edit draws from the same distribution,
# so no pairing cancels it and a single A/B build cannot resolve a sub-2% effect.
# The gate therefore ignores any delta smaller than that row's own spread, however
# large it looks - java has been observed at +3.20% against a 3.21% spread, which
# is a coin landing heads.
